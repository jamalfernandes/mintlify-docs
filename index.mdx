## The brand in five lines

|  |  |
| --- | --- |
| **Who JFC is for** | Investors building a property portfolio in the Paris region, and owners who want one apartment managed properly. |
| **What JFC does** | Buys, manages and sells, with one accountable advisor across all three. |
| **Why it matters** | Competitors do one of the three and disappear. Nobody is left accountable for what the property actually returns. |
| **How JFC sounds** | An expert who makes complicated things simple, never talks down, and is honest about risk. |
| **What proves it** | Around 40 apartments, 15 under active management, 750\+ clients accompanied in LMNP, Airbnb co-host status. |

## The one rule above all others

**Specifics instead of adjectives.** Every claim carries a number, a name or a source. The tagline promises _des conseils clairs et précis_, and woolly copy breaks that promise in the first sentence.

## How to use it

<Steps>
  <Step title="Find the block you need">
    Use the search bar. Every ready-to-use text sits in a copy block with a copy button on it, so nothing has to be retyped.
  </Step>
  <Step title="Fill the brackets">
    Anything in `[square brackets]` needs a real detail. A post with an invented number does more damage than no post at all, because this audience checks.
  </Step>
  <Step title="Check it against the voice rules">
    One pass over [the do-and-don't list](/voice). If a draft cannot be traced back to a [pillar](/messaging), and that pillar to a proof point, it does not publish.
  </Step>
</Steps>

## Language

JFC publishes in **French and English**. French is the primary language for the Paris market; English serves owners and investors living abroad.

This kit is written in English as the working reference for the Boost33 team. Every copy block carries an **FR** tab alongside the **EN** original.

<Warning>
  **The FR tabs are placeholders.** The English copy holds its structure in translation, but the rhythm does not survive a literal pass, particularly the short sentences the voice depends on. Each block needs a native French writer, not a translation engine. Never translate the tagline, and never translate the [word lists](/voice) literally.
</Warning>
