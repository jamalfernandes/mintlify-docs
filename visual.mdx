Dark, confident, and red used sparingly. The existing identity already suits the investor audience, so this **records it and sets the rules** rather than changing anything.

## Colour

| Swatch | Hex | Role |
| --- | --- | --- |
| Black | `#0A0A0A` | Backgrounds, and body text on white. The base of everything. |
| White | `#FFFFFF` | Text and space. |
| Brand red | `#FF3333` | Emphasis, links, one word in a headline. **Never body text.** |
| Deep red | `#C90404` | Buttons and hover states only, where the brighter red would vibrate. |
| Grey | `#A7A7A7` | Secondary text, rules, muted detail. |

<Warning>
  **The red rule.** Red marks the one thing that matters on a page. Two red elements competing means neither is emphasised, and the identity stops feeling deliberate.
</Warning>

## Typography

|  |  |
| --- | --- |
| **Family** | One clean sans-serif. The current site font is fine and does not need replacing. |
| **Scale** | Two or three sizes per layout. More than that reads as uncertainty. |
| **Numbers** | Set large. The proof points are the design element, not decoration around them. |

## Buttons and calls to action

One filled button per screen, one outlined alternative at most. **Button text says what happens next**, never "learn more" or "submit".
